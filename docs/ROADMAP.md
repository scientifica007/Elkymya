# خطة التطوير المرحلي — Elkymya

## الرؤية
طفل يختار ذرات الجدول الدوري بحرية ويجرب تركيبها. عند اكتشاف جزيء موثّق، يشجعه التطبيق ويعرّفه به؛ وعند تعذر المطابقة يشرح حدود الفحص بدل الادعاء بأن المادة مستحيلة. المعرفة مكافأة للتجريب، لا شرط مسبق للعب.

## v0.2 — خط أساس منشور في المستودع
خمسة عناصر، 18 بنية جزيئية، بناء وتراجع، تحليل بنيوي أولي، بطاقات عناصر، دفتر اكتشافات، RTL، عمل دون إنترنت.

## v0.3.0 — تنفيذ أولي للمحلل الإلكتروني
- ✓ إدخال اختياري للشحنة الشكلية وعدد الإلكترونات غير المزدوجة لكل ذرة.
- ✓ فحص حسابي لأزواج الإلكترونات الحرة والشحنة الإجمالية إذا اكتمل الوصف، دون استنتاج استقرار المادة.
- ✓ عدم تعريف البنية الموثقة تلقائيًا بوصفها المركب المتعادل نفسه إذا أُدخل وصف إلكتروني غير متسق أو شحنة كلية مختلفة.
- ✓ توثيق مستقل لبعض حالات الوجود الطبيعي والإنتاج الصناعي: الماء والأوزون (توسع لاحق).
- ✓ اختبارات للأنواع ذات الوصف الإلكتروني المميز، مع بقاء سجل الاكتشافات القديم.
- ✓ عدم تغيير سلوك التمرير اللمسي المحقق في v0.2.2.

## v0.3.x — العمل العلمي المتبقي
1. توسيع قاعدة البيانات الموثقة إلى معظم المركبات الحالية، مع مصادر لكل دعوى على حدة.
2. تمثيل صيغ الرنين بصورة أشمل وتقييد التعرف البنيوي بها، ثم دعم المعقدات والأيونات والجذور الموثقة بمراجع منفصلة.
3. مراجعة واجهة التوصيف الإلكتروني مع أطفال ومعلمين، واختبارها فعليًا في Brave على الهاتف.
4. تطوير تصنيف أكثر ثراءً للحالات الموثقة وغير المحسومة؛ لا يمكن لمحرك لويس وحده إثبات «ممكن نظريًا» أو «مستحيل نظريًا».

## v0.4 — عالم التفاعلات
نظام مستقل للمتفاعلات والنواتج، وموازنة المادة والشحنة، وشروط الحرارة والضغط والإشعاع والوسط، مع تمييز واضح بين بناء الصيغة ومحاكاة حدوث تفاعل.

## الإصدارات الأبعد
المحفزات وتأثيرها في سرعة التفاعل أولًا، ثم الإنزيمات والكيمياء الحيوية. لا نضيفهما إلى النسخة الأولى. التوسع نحو جدول دوري أوسع ونماذج ثلاثية الأبعاد بعد التأكد من سلامة الأساس العلمي والتربوي.

## قواعد قبول التعديل
- فحوص المحرك والتجميع آليًا قبل الدمج.
- `src/` المصدر المعتمد ويعاد منه توليد `index.html` بالنظام المحدد.
- فصل الحكم على البنية عن الحكم على التفاعل أو قابلية التحضير.
- لا يتم تقديم "غير معروف" كحكم "مستحيل".
- `main` للنسخ المختبرة؛ ميزات التطوير في `feature/*`.
