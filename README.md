# Elkymya — ذرّة | مختبر الاكتشاف الكيميائي

**الإصدار 0.2.2 — نموذج أولي للتركيب الحر للجزيئات.**

تطبيق ويب تفاعلي للأطفال باللغة العربية (RTL). يختار الطفل الذرات ويربطها بحرية، وعند مطابقة بنية جزيء موثق يحصل على التشجيع والمعلومات العلمية، مع دفتر اكتشافات يُحفظ محليًا. لا توجد أسئلة إجبارية.

## التشغيل والنشر
افتح `index.html` في متصفح حديث على الحاسوب أو الهاتف. يعمل دون خادم أو مفتاح API ودون اتصال بالإنترنت. يمكن نشره على GitHub Pages باختيار **Settings → Pages → Deploy from a branch → main / root**؛ تفعيل الاستضافة لا يتم آليًا من مجرد رفع الملفات.

## إمكانات الإصدار 0.2.2
- خمسة عناصر: H وC وN وO وCl.
- إنشاء روابط تساهمية مفردة ومزدوجة وثلاثية، وتحريك الذرات والتراجع.
- تحسين تمرير الصفحة على الهاتف: إرجاع إيماءات الخلفية للمتصفح (`touch-action: auto`) ومنع الطبقة الزخرفية من التقاط اللمس، مع الاحتفاظ بسحب الذرات. يظهر رقم الإصدار داخل المختبر للتحقق من التحديث. (تصحيح v0.2.2)
- التعرف على 18 بنية جزيئية موثقة بمقارنة الرسم الكيميائي، مع مراعاة ترتيب الروابط، لا بمقارنة الصيغة الإجمالية وحدها.
- معلومات اختيارية عند اختيار الذرة حول خصائصها وروابطها المعتادة.
- تقرير التركيب: الصيغة وعدد الذرات والروابط والكتلة التقريبية، وملاحظات على كل ذرة.
- اكتشافات محلية في `localStorage` ودفتر معلومات أولي عن الجزيئات.

## حدود الدقة العلمية
هذا الإصدار يتحقق من رسومات بنيوية مختارة، **ولا يتنبأ بإمكان وجود جميع التركيبات أو استقرارها**. ليست قواعد التكافؤ المبسطة دليلًا كافيًا للحكم بالاستحالة؛ فقد تلزم معلومات عن الشحنات، والجذور الحرة، والرنين، وحالات الطاقة، والشروط التجريبية. "غير مدرج" ليست "غير ممكن". ليس محاكي تفاعلات ولا حسابًا كموميًا، ولا يتضمن إنزيمات أو محفزات حاليًا.

راجع [السياسة العلمية](docs/SCIENTIFIC_POLICY.md) و[خارطة التطوير](docs/ROADMAP.md).

## بنية المشروع
- `index.html`: ملف موحد للنشر وفتح التطبيق مباشرة.
- `src/document-head.html` و`src/body.html` و`src/styles.css`: بنية الواجهة.
- `src/engine.js`: البيانات الكيميائية ومحرك التعرف والتحليل.
- `src/app.js`: الرسم والتفاعلات وسجل الاكتشافات.
- `scripts/build.mjs`: تجميع ملف النشر من الشيفرة المصدرية.
- `tests/engine.test.js`: اختبارات المحرك.
- `.github/workflows/ci.yml`: تحقق آلي عند تحديث المستودع.

## العمل على المشروع
يحتاج Node.js إصدار 18 أو أحدث؛ لا يحتاج إلى تنزيل مكتبات خارجية.
```bash
npm run build
npm test
npm run check:syntax
```

**آلية التطوير:** يعتمد `main` نسخة مجربة، وتنفذ التغييرات الكبيرة في فروع `feature/*` وتُراجع قبل دمجها. يقتضي كل تعديل يخص الحكم العلمي اختبارًا مناسبًا ومصدرًا واضحًا. لا يعني طلب التطوير المستمر تشغيل تعديلات تلقائية دون مراجعة؛ تستمر الإصدارات عند طلب تطوير جديد.

مرجع علمي عام: [IUPAC Gold Book](https://goldbook.iupac.org/) و[PubChem](https://pubchem.ncbi.nlm.nih.gov/).
